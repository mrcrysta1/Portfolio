# Ali Hassan - Portfolio

Personal portfolio website for Ali Hassan, a passionate Full-Stack Developer and Cyber Researcher.

## Tech Stack

- HTML5, CSS3, JavaScript
- Bootstrap 5 + Swiper
- AOS (scroll animations)
- PHP (contact form handling)

## Features

- Fully responsive design
- Portfolio and project showcase
- Blog section
- Services section
- Working contact form

## Getting Started

Serve the project from any PHP-enabled web server:

    php -S localhost:8000

Then open http://localhost:8000 in your browser.

## Project Structure

- `index.html` / `index.php` - home page
- `about.html` - about section
- `portfolio.html` - projects showcase
- `service.html` - services
- `blog.html` / `blog-single.html` - blog
- `contact.html` - contact form
